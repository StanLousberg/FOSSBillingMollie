# MolliePayments

Zelfstandige Mollie-integratie voor FOSSBilling.

GitHub-repository: `StanLousberg/FOSSBillingMollie`. De productnaam is `MolliePayments`.

De meegeleverde PHP-bestanden zijn uitsluitend een ontwikkelskelet. Betalingen zijn uitgeschakeld.
De manifestlicentie is voorlopig `Apache-2.0`; bevestig je definitieve licentiekeuze en voeg voor publicatie een passend LICENSE-bestand toe.

## Ontwikkelen

De FOSSBilling-testhost staat in dezelfde workspace, twee directoryniveaus boven deze repository.
De koppelingen worden lokaal aangebracht via symlinks en horen niet in upstream FOSSBilling.
